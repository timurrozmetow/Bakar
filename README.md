# BAKAR — сайт + админ-панель

Полноценное решение для бренда продуктов питания **BAKAR**: публичный трёхъязычный сайт
(туркменский / русский / английский) и админ-панель для управления контентом.

- **Сайт** — порт дизайна Bakar на React: hero-карусель, ассортимент, статистика, отзывы,
  сертификаты, форма «Стать партнёром». Светлая/тёмная тема, переключатель языка TM / RU / EN.
  Полный адаптив (мобильный/планшет/десктоп), анимации при скролле (Framer Motion),
  SEO (мета-теги и `<html lang>` под каждый язык, Open Graph, JSON-LD, robots.txt, sitemap.xml,
  favicon), скелетоны загрузки, индикатор прокрутки и кнопка «наверх».
- **Админка** (`/admin`) — управление баннерами, категориями, продукцией (с вариантами фасовки),
  сертификатами (с загрузкой PDF), отзывами, текстами страниц и заявками партнёров. Загрузка и
  автоматическая оптимизация изображений, **сортировка перетаскиванием**, смена пароля и профиля.

### Безопасность
- `helmet` (заголовки безопасности), защита от перебора пароля (10 попыток / 15 мин),
  лимит на форму заявок (5 / час) и общий лимит API.
- Смена пароля и e-mail администратора прямо в интерфейсе (`/admin/profile`).
- Загруженные файлы удаляются с диска вместе с записью — но только если на них больше никто не ссылается.

### SEO и скорость
- **Страницы товаров** с отдельными URL (`/products/<slug>`) и разметкой schema.org Product.
- **Мета-теги подставляются на сервере**: когда Express раздаёт собранный сайт, краулер получает
  готовые `<title>`, `description`, Open Graph и JSON-LD прямо в HTML (важно для SPA).
- Динамические `sitemap.xml` и `robots.txt`, собранные из базы (включая все товары).
- **Адаптивные изображения**: эндпоинт `/img/<файл>?w=` отдаёт webp нужной ширины с дисковым кэшем, на сайте — `srcset`.
- Код разделён на чанки: админка (~120 КБ) грузится только при заходе в `/admin`.

### Уведомления о заявках
Заявка из формы «Стать партнёром» уходит в Telegram и/или на e-mail — если заполнить
соответствующие переменные в `server/.env` (см. `.env.example`). Без настройки просто не отправляется.

## Требования

- Node.js 20+
- MySQL 8+ (запущенный экземпляр)

## Быстрый старт

### 1. База данных
Создайте пустую БД в MySQL:
```sql
CREATE DATABASE bakar CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 2. Переменные окружения сервера
```bash
cd server
cp .env.example .env
```
Отредактируйте `DATABASE_URL` под свои логин/пароль MySQL, например:
```
DATABASE_URL="mysql://root:ВАШ_ПАРОЛЬ@localhost:3306/bakar"
```
При желании поменяйте `ADMIN_EMAIL` / `ADMIN_PASSWORD` и `JWT_SECRET`.

### 3. Установка и инициализация
Из корня проекта:
```bash
npm install                 # ставит concurrently
npm run install:all         # ставит зависимости server и client
npm run db:setup            # prisma generate + db push + seed (создаёт схему и контент)
```

### 4. Запуск (dev)
```bash
npm run dev
```
- Сайт: http://localhost:5173
- Админка: http://localhost:5173/admin
- API: http://localhost:4000

**Вход в админку:** `admin@bakar.tm` / `admin12345` (или то, что задали в `.env`).

## Как это работает

- Все текстовые поля хранятся как JSON `{ tm, ru, en }`. В админке у каждого поля вкладки
  **TM / RU / EN**; на сайте показывается версия для выбранного языка (с откатом на RU).
- Публичный сайт получает весь контент одним запросом `GET /api/public/site` (только активные записи).
- Изображения загружаются через `POST /api/uploads`, сжимаются в webp (sharp) и раздаются из `/uploads`.
- Заявки из формы «Стать партнёром» падают в раздел **Заявки** админки.

## Полезные команды

| Команда | Действие |
|---------|----------|
| `npm run dev` | сервер + клиент в dev-режиме |
| `npm run build` | продакшн-сборка обоих |
| `npm run db:setup` | схема БД + сиды заново |
| `npm run db:seed --prefix server` | пересеять контент |
| `npx prisma studio` (в `server/`) | визуальный редактор БД |

## Продакшн (кратко)

1. `npm run build` — соберёт `server/dist` и `client/dist`.
2. Раздайте `client/dist` любым статическим хостингом (или через тот же Express).
3. Запустите API: `cd server && npm start` (нужны `.env` и доступная MySQL, выполните `prisma migrate deploy` / `db push`).
4. Настройте `CLIENT_ORIGIN` и `PUBLIC_URL` в `.env` сервера под ваш домен.
